Документация API

Проверяйте доступность сервиса, получайте грозовые индексы и графики погоды. Интерактивные формы ниже отправляют реальные запросы текущему серверу.

Безопасность для публичного развёртывания. Публичным сейчас является только GET /api/health. Все остальные /api/* требуют X-API-Key. Не встраивайте общий секретный ключ в публичный сайт/клиент: посетители смогут его извлечь. Для открытого публичного приложения используйте собственный серверный прокси с авторизацией, лимитами и квотами. Ключ в форме ниже хранится только в памяти этой вкладки и не записывается в localStorage.

Интерактивная проверка

Документация и health-check открыты. Для защищённых запросов введите свой ключ — он уйдёт только в заголовке HTTPS/HTTP запроса к этому серверу. На обычном HTTP в публичной сети ключ передаётся без шифрования.

Результаты запросов появятся здесь.

Маршруты

ПУБЛИЧНЫЙ · без ключа

GET/api/health

Проверка, что API запущен. Не подтверждает работоспособность внешних погодных источников.

curl http://127.0.0.1:8000/api/health
ТРЕБУЕТ КЛЮЧ

GET/api/time-offsets

Допустимые значения времени прогноза. Удобный запрос для проверки ключа.

curl -H "X-API-Key: YOUR_KEY" http://127.0.0.1:8000/api/time-offsets
ТРЕБУЕТ КЛЮЧ

GET/api/geocode

Поиск координат города. Возвращает название, широту и долготу.

GET /api/geocode?query=Екатеринбург
ТРЕБУЕТ КЛЮЧ

GET/api/storm

Грозовой отчёт с индексами, источником данных и форматированным текстом.

GET /api/storm?lat=56.8333&lon=60.5833&city=Екатеринбург&time_index=0
ТРЕБУЕТ КЛЮЧ

GET/api/chart/profile

PNG вертикального профиля атмосферы. Использует общие координаты и время из формы грозового отчёта.

GET /api/chart/profile?lat=56.8333&lon=60.5833&city=Екатеринбург&time_index=0
ТРЕБУЕТ КЛЮЧ

GET/api/chart/skewt

PNG Skew-T Log-P диаграммы по модельному профилю. Использует общие параметры координат/времени.

GET /api/chart/skewt?lat=56.8333&lon=60.5833&city=Екатеринбург&time_index=0
ТРЕБУЕТ КЛЮЧ

GET/api/radar

PNG-изображение радара осадков. Время и признак кэша передаются в заголовках ответа.

GET /api/radar?lat=56.8333&lon=60.5833&city=Екатеринбург
ТРЕБУЕТ КЛЮЧ

POST/api/ai-analysis

AI-анализ погодных условий. Требуется доступность хотя бы одного настроенного AI-провайдера или fallback-провайдера.

POST /api/ai-analysis
Content-Type: application/json
X-API-Key: YOUR_KEY

{"lat":56.8333,"lon":60.5833,"city":"Екатеринбург","time_index":0}

Авторизация и ответы

  • /api/health — публичный endpoint, ключ не нужен.
  • Для всех прочих /api/* отправляйте X-API-Key: <значение API_ACCESS_KEY>. При пустом ключе на сервере защищённые маршруты закрыты.
  • 401 Unauthorized — ключ не передан/не совпал или не настроен серверный ключ; 429 Too many requests — превышен лимит 60 запросов в минуту на ключ.
  • Прогнозный time_index: 0 — сейчас, 1 — +3 ч, 2 — +6 ч, 3 — +12 ч, 4 — +24 ч. Координаты: широта от -90 до 90, долгота от -180 до 180.
  • На публичном сайте нельзя безопасно раздать один общий секрет клиентскому JavaScript. Страница документации не открывает защищённые endpoints и не показывает настроенный ключ.
